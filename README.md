# Nadeer Ansari — Portfolio

A professional dark-theme portfolio for Nadeer Ansari, a Java Backend Developer and Software Engineer. Built with React and Vite.

## Featured work

- Smart Society Connect — React, Spring Boot, MySQL, JWT and Docker
- CineScope — React, Redux Toolkit, Bootstrap and TMDB API
- Node.js CRUD API — Node.js, Express, MongoDB, EJS and Bootstrap

## Development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Structure

```text
public/             Profile, project and résumé assets
src/App.jsx         Portfolio content and components
src/index.css       Responsive visual system
src/main.jsx        React entry point
index.html          Metadata and application shell
```
